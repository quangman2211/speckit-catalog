# Frontend A11y Gate

Cong kiem tra a11y chay truoc `__SPECKIT_COMMAND_IMPLEMENT__`.

## User Input

$ARGUMENTS

## Steps

1. Doc `wcag_level` tu `.specify/extensions/frontend/frontend-config.yml`
   (mac dinh `AA`).
2. Doc `spec.md` va `plan.md` cua feature hien tai.
3. Doi chieu tung tieu chi ap dung duoc:
   - Contrast toi thieu 4.5:1 cho text thuong, 3:1 cho text lon
   - Moi control tuong tac deu den duoc bang ban phim, co focus indicator
   - Form control co label lien ket, thong bao loi doc duoc bang screen reader
   - Khong dung mau lam kenh truyen dat thong tin duy nhat
   - Target size toi thieu 24x24 CSS px (WCAG 2.2)
   - Noi dung dong (toast, modal) co live region phu hop
4. Xuat bang ket qua: tieu chi | trang thai | vi tri trong spec | de xuat sua.
5. Neu co muc **FAIL**, dung lai va yeu cau nguoi dung cap nhat spec bang
   `__SPECKIT_COMMAND_SPECIFY__` truoc khi implement.

## Rules

- Chi bao FAIL khi spec noi ro dieu vi pham. Spec im lang ve mot tieu chi thi
  bao GAP, khong bao FAIL.
- Khong tu sua spec. Chi bao cao va de xuat.
